= NEM12 Meter Reader

This project is a NEM12 Meter Reader system that reads meter readings from a NEM12 format file and writes the data into a database. The system is modularized and consists of two modules and a queue for data transmission.

== Project Modules

* `meter-data-preprocessor`
** Reads and parses NEM12 format files.
** Sends parsed data to the queue for downstream processing.

* `meter-reading-dbwriter`
** Listens to the queue and receives meter reading data.
** Writes the readings into the database.

* `queue`
** https://github.com/OpenHFT/Chronicle-Queue[Chronicle-Queue] is provided as a sample queue implementation.
** Acts as the communication channel between the preprocessor and the database writer.

== Usage

1. Ensure the queue service is up and running.
2. Start the `meter-reading-dbwriter` module first.
3. Start the `meter-data-preprocessor` module to begin reading and processing NEM12 files.

== Notes

* The architecture supports scaling: multiple preprocessors and database writers can be deployed for higher throughput.
